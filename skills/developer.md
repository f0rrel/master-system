# Skill: developer

General product work that spans structure, behaviour and presentation.

- Read the relevant code and the existing tests before changing anything.
- Make the smallest change that satisfies the description and the acceptance tests.
- Follow the project's existing style, naming and file layout; do not reformat unrelated code.
- Replace old code instead of keeping it as a fallback.
- Keep the project runnable: no new build steps or dependencies unless the task asks for them.
