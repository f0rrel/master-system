# Skill: logic

Work on rules, state, data and algorithms, without changing presentation.

- Keep logic in pure, testable functions where the project allows it.
- Handle edge cases explicitly (empty input, limits, invalid states).
- Determinism matters: use the project's seeded random source where one exists.
- Do not change styling or layout unless the task requires it to expose the logic.
- Tasks are sized to about 150 lines. Write the first part of a new file in your first
  steps, then add the rest with further edits; never hold a whole large file in your head.
